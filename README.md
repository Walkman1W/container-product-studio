# 集装箱数据中心 · 产品浏览器

三列中文 Three.js 产品浏览器，内含 20HC、40HC 两款真实 GLB 模型以及完整外观 / 剖切展示版本。模型几何与原始交付一致，公开元数据经过白名单清理。

## 已实现

- 左侧：产品切换、设备 / 系统构件树、名称及编号搜索
- 中间：旋转、平移、缩放、选择高亮、隐藏 / 恢复、隔离、聚焦、建筑 / IT / 制冷 / 供配电 / 辅助系统开关、区域标识开关、轴测与带中文标签的 SVG 功能平面视图
- 右侧：当前选中对象的元数据、实际模型包围盒、设备标称尺寸与依据来源、产品参数；厂家平面局部图、原创设备尺寸示意与依据说明
- WebGPU 优先：检测安全上下文与可用适配器并尝试初始化；不支持时回退到 WebGL 2。页面右上角显示实际初始化的后端，不会将兼容模式误报成 WebGPU。
- 手机布局会将产品、模型与属性按顺序排列；桌面采用三列布局
- 模型下载进度、错误提示、重试以及重复切换的取消处理
- 如果浏览器连 WebGL 2 都不可用，会明确显示静态预览模式，以原模型渲染图替代空白画布。产品切换、构件搜索和参数读取仍可使用；三维旋转、隐藏、隔离等需要图形上下文的控制会禁用；SVG 平面缩放、平移和设备选择照常可用。

## 构建与静态部署

此 GitHub 仓库包含源码、模型和参考图，不包含构建产物。先运行下方的 `npm ci`、`npm test`、`npm run build`，生成的 `dist/` 可以直接托管，不需要 Node.js 后端或数据库。

1. 将 `dist/` 文件夹内的全部内容上传到网站的静态根目录（必须同时上传 `assets/`、`models/` 和其他文件）。
2. 使用 Nginx、Apache、Caddy 或其他 HTTP 静态服务器提供文件。
3. 用浏览器打开 HTTP / HTTPS 地址。

不要双击 `index.html` 以 `file://` 方式打开：浏览器对 ES 模块和模型请求的安全限制会阻止加载。

建议启用 HTTPS，以允许 WebGPU 在支持它的浏览器 / 显卡上使用。仅在 localhost 开发时，HTTP 也通常属于安全上下文。WebGPU 不可用时仍会尝试 WebGL 2。

### 本机快速启动（Python 3）

完成构建后，在项目目录运行：

```sh
python3 -m http.server 8080 --directory dist
```

浏览器打开 `http://localhost:8080/`。这适合本机查看，不建议将 Python 开发服务器直接暴露为正式生产服务。

### Nginx 示例

将 `dist/` 内容复制到 `/var/www/container-viewer/`，配置示例：

```nginx
server {
    listen 80;
    server_name your-domain.example;
    root /var/www/container-viewer;
    index index.html;
    location / {
        try_files $uri $uri/ =404;
    }
    location ~* \.glb$ {
        add_header Content-Type model/gltf-binary;
        try_files $uri =404;
    }
}
```

正式部署请按您的服务器方式配置 TLS / HTTPS。构建采用相对路径，也可部署在子目录中，访问该子目录带结尾 `/` 的地址即可。

## 修改源码后重建

需要 Node.js 20.19+、22.12+ 或兼容的更新版本，以及 npm。

```sh
npm ci
npm test
npm run build
```

将新生成的 `dist/` 重新上传。开发预览：

```sh
npm run dev
```

依赖已锁定在 `package-lock.json` 中。Three.js 版本为 0.180.0，Vite 版本为 8.0.13。首次安装依赖需要网络；构建后的网站不依赖外部 CDN，模型与 JavaScript 都随包提供。点击“来源资料”链接时会打开外部厂家网站。

## 模型与参数的边界

- 20HC：外形 6058 × 2438 × 2896 mm，3 台 IT 机柜。
- 40HC：外形 12192 × 2438 × 2896 mm，按平面图显示 7 台 IT 机柜。来源参数表列 8 台，差异待厂家确认。
- 模型坐标单位是米。界面中的包围盒以世界坐标 X × Y × Z 显示，Y 为高度；设备标称尺寸单独按宽 × 深 × 高显示。
- 此为 IDC 产品展示与布局参考，未完成 GPU / AIDC 工程验证，不是 LOD400 或制造发布模型。模型细部包含参考假定，不代表完成制造、安装、消防或运维验证。
- 剖切版会移除部分墙面 / 屋顶，因而构件树与网格总数会少于完整模型；这属于原始剖切 GLB 的内容。
- 网站 WebGPU 是浏览器渲染技术，与 GPU 数据中心的工程能力认证是两回事。

## 文件

- `src/`：页面逻辑与样式
- `index.html`：三列界面
- `public/models/`：四个 GLB
- `public/model-manifest.json`：模型文件 SHA-256、网格与节点数量
- `scripts/validate-models.mjs`：模型格式、数量、校验和与敏感路径检查
- `dist/`：运行构建命令生成的网站，可直接静态部署（不提交到仓库）

模型直接存放在 Git 仓库，不需要 Git LFS。发布自托管时只需上传构建后的 `dist/` 内的文件。

## 操作

- 鼠标左键拖动旋转；右键拖动平移；滚轮缩放；手机单指旋转、双指缩放和平移。
- 点击模型或构件树选择对象。树的行首小箭头展开下级；点击行名称选择设备 / 系统。
- “选择层级”决定模型点击选中整个设备 / 系统，还是单个构件。
- “聚焦”使选中对象适合视口；“隔离”暂时只显示选中对象。
- “恢复显示”恢复当前 GLB 的全部实体；区域标识默认为关闭，可单独开启。
- 平面视图是独立 SVG，可在无 WebGPU / WebGL 2 的浏览器使用。完整模型设备包络与现有区域投影为基准，不受剖切隐藏柜板影响。包含中文设备名称、冷热区、纵向通行区域、出入口示意、尺寸及图例。
- 平面滚轮或按钮缩放，拖动平移，“全图”复位；设备可点击或用 Tab / Enter 选中。平面文字与分区可单独开关。
- 右侧厂家原图局部可点击放大，Escape 关闭。厂家原图、原创尺寸解读图与模型派生 SVG 分开标识。
- `/` 聚焦搜索框，模型视口获得焦点后按 `F` 适配全景，`Esc` 取消选择。

## SVG 平面数据

`public/plan-data.json` 保存 20HC / 40HC 的设备完整包络、区域坐标、消防占位、示意门洞和依据状态。坐标来自现有模型及几何报告，27 个功能设备包络已与完整 GLB 核对；原 Blender XY 平面对应 GLB X / −Z，SVG 使用 x = x、y = −y − height。

`glbPlanBounds` 是剖切版隐藏外板后的局部可见包络，绘制完整占位时使用顶层 x/y/width/height。每侧 150 mm、638 mm 纵向区域、通行线与消防瓶适配位置仍是模型参考，不是施工或疏散验证。

`public/references/` 仅包含两款原始平面局部引用，不分发完整厂家手册。版权归 INVT，页面链接官方 PDF。
